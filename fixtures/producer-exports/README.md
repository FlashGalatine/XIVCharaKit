# Maintainer-supplied producer exports

These four files are byte-identical copies of default-setting exports supplied by the maintainer on 2026-10-20. They represent the maintainer's own player character. In the supplying conversation, the maintainer confirmed ownership and permission to redistribute them where necessary; they are retained here as project test fixtures. This is a contributor permission record, not a new license selection for the project or game-derived data.

The maintainer described the applications as their latest versions. Exact application versions were not supplied and are not inferred from stored Version or FileVersion fields. The two Anamnesis exports differ only in Author, Description and Version metadata. Personal character metadata in the supplied originals is retained under that permission; these files are not anonymized synthetic examples.

Source-byte SHA-256 values and provenance are in [the manifest](../manifest.json). File names here identify producer/settings; no source paths are recorded. The files are test-only: they are not copied to the demo's public examples or included in the package tarball.

[Regression tests](../../packages/chara/test/producer-exports.test.ts) check directly reviewed stored identity, customization, model, dye, facewear and extended-validity expectations, plus documented Brio diagnostics and successful appearance interpretation. They do not establish in-app visual ground truth, partial-export compatibility or every producer/version combination. See [remaining validation](../../docs/producer-fixture-validation.md).
